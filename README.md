# Personal Portfolio Website

A modern, responsive single-page developer portfolio built with HTML5, CSS3, and JavaScript. Features a dark-mode matrix aesthetic with animated gradient backgrounds, glassmorphism cards, and dedicated sections showcasing software engineering projects, system architecture case studies, professional experience, and technical skill sets.

## Tech Stack
- **Frontend:** HTML5, CSS3 (CSS Variables, Flexbox/Grid Animations), JavaScript
- **Backend Projects Highlighted:** PHP, MySQL, XAMPP
- **Tools & Methodologies:** Git, GitHub, ADD Architecture, Network Assessment Tools (Nmap, Kali Linux)
